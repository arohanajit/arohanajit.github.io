# Arohan Ajit

## 💫 About Me

As a passionate software developer with a Master's in Computer Science from **North Carolina State University**, I thrive on turning complex challenges into elegant solutions.

My journey has evolved from crafting responsive web applications at **Accenture** and optimizing critical API endpoints at **Chirpn**, to engineering large-scale infrastructure capacity planning systems at **Google** and implementing end-to-end Agentic AI solutions at **Yahoo**.

With expertise in **Python**, **ReactJS**, **Node.js**, **Java**, and cloud technologies like **AWS** and **Azure**, I'm always eager to dive into new technologies and push the boundaries of what's possible.
